Neon Ark Project 
Notes: 
1.  Create New Project in Intellij
2.  Select Springboot- Add the following dependencies 
    Spring Web
    Spring Data JPA
    PostgreSQL Driver
    Flyway Migration
    Lombok

3.   Create PostgreSQL database connection.  Enter host name, port, user and databasename and test the connection
4.   Create Creature Entity
5.   Create Habitat Entity
6.   Create Migrations to create creatures and habitat tables
7.   Create Migration to connect creations database to habitat based on habitId (note you can run the migrations manufally or they will run when the Springboot server is started
8.    Create Migration to create seed data
9.    Create Creatures Repository
10.   Crate Habitat  Repository
11.   Create Creatures Service
12.   Create Creatures Controller
13.   Add customized exception handling
14.   Test the application
